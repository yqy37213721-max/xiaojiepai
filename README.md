## 🏗 项目架构

- **前端**: 纯静态 HTML + CSS + JavaScript（完全移动端自适应）
- **后端**: Supabase（免费 PostgreSQL 数据库 + Realtime 实时同步）
- **实时通讯**: Supabase Realtime（Postgres Changes）
- **适用平台**: 微信内置浏览器 / 手机浏览器 / PC 浏览器
- **部署**: 支持 Vercel / Netlify / GitHub Pages / 任何静态托管

### 数据流

```
微信用户A ──→ 创建房间 ──→ 分享房间号/链接 ──→ 微信用户B 加入
         ↓                                       ↓
   [ 所有人都实时同步 ] ←── Supabase Realtime ──→ [ 游戏状态 ]
         ↓                                       ↓
  A 抽牌 → 状态写入数据库 → 推送变更 → B/C/D 自动更新
```

## 🚀 快速开始 - 部署教程

### 前置条件

1. 一台电脑（用于配置和部署）
2. 一个 GitHub 账号（免费，用于托管代码）
3. 一个 Supabase 账号（免费，用于后端数据库）

> **全部使用免费套餐，零成本部署！**

---

### 第一步：搭建 Supabase 后端（约 10 分钟）

1. **注册 Supabase**
   - 打开 [supabase.com](https://supabase.com)
   - 点击 "Start your project"
   - 使用 GitHub 账号登录

2. **创建项目**
   - 点击 "New project"
   - 填写项目名称（例如 `xiao-jie-pai`）
   - 设置数据库密码（**保存好！**）
   - 选择区域（选最近的，如 Tokyo 或 Singapore）
   - 点击 "Create new project"（等待 2-3 分钟）

3. **获取 API 密钥**
   - 项目创建完成后，进入 **Project Settings** → **API**
   - 复制 **Project URL**（格式如 `https://xxx.supabase.co`）
   - 复制 **anon public key**（一串长长的 base64 字符串）
   - **暂存这两个值，后面需要用到**

4. **执行建表 SQL**
   - 进入 **SQL Editor**
   - 点击 "New query"
   - 打开项目中的 `supabase.sql` 文件，**复制全部内容**
   - 粘贴到 SQL Editor，点击 **"Run"** 执行
   - 再打开 `supabase_migration.sql`，同样复制粘贴执行

5. **启用 Realtime**
   - 进入左菜单 **Realtime**
   - 确保这三张表已启用：
     -  ✔ `rooms`
     -  ✔ `players`
     -  ✔ `game_state`
   - 如果未启用，点击 "Add table" 手动添加

---

### 第二步：配置前端（约 2 分钟）

1. 用文本编辑器（记事本/VS Code）打开 `js/config.js`

2. 替换成你的 Supabase 密钥：

```javascript
const SUPABASE_CONFIG = {
  url: 'https://你的项目ID.supabase.co',  // ← 替换！
  anonKey: '你的anon-key-here'             // ← 替换！
};
```

3. **保存文件**

---

### 第三步：部署到线上（约 5 分钟）

#### 方法 A：部署到 Vercel（推荐，最简单）

1. 前往 [vercel.com](https://vercel.com) 并注册（推荐用 GitHub 登录）
2. 点击 **"Add New"** → **"Project"**
3. 导入你的 GitHub 仓库（先把项目文件 push 到 GitHub）
4. 或者点击 **"Deploy without Git"**
   - 使用 Vercel CLI：安装后运行 `npx vercel`
   - 将 `小姐牌/` 文件夹作为项目目录
   - 设置输出目录为 `小姐牌`
5. 部署完成后，Vercel 会给你一个域名（如 `xxx.vercel.app`）

#### 方法 B：部署到 GitHub Pages

1. 在 GitHub 新建仓库，上传 `小姐牌/` 全部文件
2. 进入仓库 **Settings** → **Pages**
3. Source 选择 "Deploy from a branch"
4. Branch 选择 `main`，目录选择 `/ (root)`
5. 部署完成后，你的网址为：`https://你的用户名.github.io/`

#### 方法 C：使用微信云开发（最方便）

如果你有微信小程序的云开发资源，也可以直接用云存储托管静态页面，在微信内打开体验最好。

---

### 第四步：在微信中分享（即点即玩）

1. 将部署好的网址发送到微信群
2. **在微信内点击链接**即可打开（无需下载、无需注册）
3. 一人点击"创建房间"，生成 4 位房间号
4. 其他人点击"加入房间"输入房间号，或直接点击分享的链接
5. 所有人到齐后，房主点击"开始游戏"
6. **轮流抽牌，按规则喝酒** 🍻

> 💡 **小技巧**：长按分享链接 → 选择"收藏"，下次可以在微信收藏中快速打开。

## ❓ 常见问题

### Q: 需要注册账号吗？
**完全不需要**。昵称存在本地浏览器中，使用 UUID 标识玩家，即点即玩。

### Q: 最多支持多少人同时玩？
理论最多 10 人，实际建议 **2-8 人** 体验最佳。

### Q: 必须用微信吗？
不。任何浏览器都可以打开，但**在微信内体验更佳**（点击链接即开）。

### Q: 数据安全吗？
房间数据在游戏结束后可手动清理。Supabase 有行级安全策略（RLS），且使用 anon key（只读/写入权限受 SQL 策略限制）。

### Q: 如何开始新一局游戏？
游戏结束后房主可以看到"再来一局"按钮，其他人自动同步。也可以全部退出后重新创建房间。

### Q: 游戏过程中有人退出/断线了怎么办？
该玩家会被标记为离线。游戏可以继续正常进行，离线玩家回来后可以看到最近的状态。
